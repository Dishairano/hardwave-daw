### Improvements
- feat(daw): see which track is eating the CPU
- feat(daw): play just the selection, and glue clips into one
- Edit > Play selection (Shift+Space) plays from the first selected clip to the end of the last and stops.
- Right-click a clip and pick Consolidate selected clips to render that stretch of the track, with its plug-ins, into one clip.
- Each mixer strip shows how much of the audio block that track is using, so you can see which one to bounce when the CPU meter climbs.
