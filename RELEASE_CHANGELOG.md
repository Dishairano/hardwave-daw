### New features
- feat: step editing is back and works. On, the typing keyboard writes notes into the open clip and steps forward. Off, the keys only play, so you can try a part without writing it

### Bug fixes
- fix: the MEM meter now shows how much memory Hardwave is really using, including your samples and plug-ins, as a share of your machine. It used to show the interface's own memory, which stayed small no matter how big the project got
- fix: the typing keyboard no longer writes a note into your clip every time you press a key to hear something

### Improvements
- improve: moving a fader, muting, soloing or renaming a track in a big project no longer sends the whole project back and forth for one change, so the mixer stays responsive
